## Forcella 🍕
React app with Firebase Realtime Database, protected routes, and scalable, accessible components.

## 🧩 Overview
A modern pizza ordering web app built with React and Material UI, designed with scalable architecture, reusable components, accessibility, and support for dark mode and multiple languages.

## 🎯 Project Goals
The goal of this project was to gain hands-on experience building a complex, real-world React application using modern tools and libraries. I focused on clean architecture, reusable components, React hooks, and integrating technologies like Material UI, React Hook Form, and i18n, while challenging myself to develop a scalable multi-page app with realistic user flows.

## 🛠 Tech Stack
- React
- React Router
- React Hook Form
- Material UI
- Firebase
- i18next
- 
## ✨ Main Features
- Welcome page
- Login and signup (Firebase authentication)
- Guest access
- Dynamic pizza menu
- Wishlist
- Cart and payment flow
- Editable user profile
- Protected routing
- Multi-page navigation
- Multilingual support (English and Italian)
- Dark and light theme

## ⚠️ Challenges I Faced
- Lack of initial data planning, leading to refactoring and increased complexity
- Managing async state and timing between providers and data consumers
- Handling and structuring objects effectively (spreading, updating, and reuse)

## 🤖 How I Used AI
- Assisted in setting up and integrating libraries and tools
- Supported debugging after initial implementation, especially for async state issues
- Provided guidance on refactoring and improving component structure
- Helped in creating custom hooks and utility functions
- Assisted with translating content into Italian (i18n)
- Suggested improvements for Material UI styling and customization
